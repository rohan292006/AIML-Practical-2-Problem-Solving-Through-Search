# AIML Practical 2 - Problem Solving Through Search

## Practical Title

Performance Evaluation of Various Search Algorithms

## Algorithms Implemented

1. Breadth First Search (BFS)
2. A* Search
3. Hill Climbing
4. CSP Backtracking

## Objective

To implement and evaluate different problem-solving techniques through search and compare their performance using nodes/steps explored and execution time.

## Search Categories

| Algorithm | Search Category |
|---|---|
| BFS | Uninformed Search |
| A* | Informed Search |
| Hill Climbing | Local Search |
| CSP Backtracking | Constraint Satisfaction |

## Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Heapq

- Time

## Implementation

The notebook contains implementations of:

- BFS path search
- A* heuristic search
- Hill Climbing optimization
- CSP Backtracking for map colouring

## Performance Evaluation

The algorithms are compared using:

- Nodes / Steps
- Execution Time

The execution time may vary depending on the runtime environment.
